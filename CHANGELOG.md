# Historia zmian strony StarMess

## 1.2.1 — 2026-10-26

- Ogólny, krótki opis gry zastępuje wyliczenia funkcji i promocyjne hasła w EN/PL/RU.
- Usunięto drobne etykiety, dopiski, statystyki i pustą zapowiedź filmów; zwiększono czytelność pozostałego tekstu.
- TikToki można dodawać jako same linki, bez dodatkowych podpisów.

## 1.2.0 — 2026-10-26

- Krótsze opisy gry i swobodniejsze teksty EN/PL/RU, z konkretnymi informacjami o prototypie.
- Cieplejsza oprawa, prostsze sekcje i przyciski z pikselowym cieniem.
- Pusta sekcja TikToka pokazuje jedną zapowiedź zamiast trzech atrap filmów.

## 1.1.2 — 2026-10-26

- Angielska wersja jest domyślna na stronie głównej i pierwsza w wyborze języka.
- Polski pozostaje pod /pl/; domyślne odnośniki SEO wskazują wersję angielską.

## 1.1.1 — 2026-10-26

- Konfiguracja deployu Vercel z repozytorium GitHub zastępuje GitHub Pages.
- Adres produkcyjny Vercel zasila metadane SEO; podglądy mają noindex.
- Każdy build Vercel uruchamia testy przed publikacją.

## 1.1.0 — 2026-10-26

- Osobne strony PL/EN/RU z pełną treścią, galerią i changelogiem w HTML.
- Canonical, hreflang, sitemapa i robots.txt z adresem przekazywanym przez GitHub Pages.
- Zlokalizowane podglądy udostępniania i dane strukturalne gry.
- Nawigacja językowa i starsze aktualizacje działają także bez JavaScriptu.

## 1.0.0 — 2026-10-26

- Landing page PL/EN/RU z opisem gry, galerią i przełączaniem języka.

- Pełny dziennik zmian gry z importem trzech języków.
- Build statyczny, walidacja treści i workflow GitHub Pages.
